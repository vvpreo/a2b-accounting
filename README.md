# finances-v2

Проект для учёта и планирования личных финансов В3П.

Десктопное приложение с акцентом на работу с таблицами и скорость разработки.

## Технологический стек

### Оболочка и сборка
- **Tauri 2** — нативное десктоп-приложение (macOS / Windows / Linux)
- **Vite** — сборщик фронтенда

### Фронтенд
- **React 18 + TypeScript** — UI-фреймворк
- **Tailwind CSS** — стилизация
- **shadcn/ui** — библиотека UI-компонентов (копируются в проект)
- **TanStack Table** — таблицы (сортировка, фильтрация, группировка, виртуализация)
- **TanStack Query** — управление состоянием данных
- **Zustand** — глобальное состояние приложения
- **Zod** — валидация схем данных

### Хранилище
- **SQLite** через `tauri-plugin-sql` — локальная база данных

## Переменные окружения

- **`FINANCES_DATA_DIR`** (обязательная) — путь к директории, в которой приложение хранит все данные (SQLite-базу и всё, что появится позже). Если директории нет, она будет создана при старте. Если переменная не задана — приложение завершится с ошибкой.

## Запуск

### Требования
- Node.js ≥ 20
- Rust (stable) — устанавливается через [rustup](https://rustup.rs/)
- macOS: Xcode Command Line Tools (`xcode-select --install`)

### Первичная установка зависимостей
```bash
npm install
```

### Режим разработки
```bash
export FINANCES_DATA_DIR="$HOME/.finances-v2"
./scripts/dev.sh
```

### Сборка десктоп-приложения
```bash
./scripts/build.sh
```

Установщики и бандлы появятся в `src-tauri/target/release/bundle/` (на macOS — `.app` и `.dmg`).
